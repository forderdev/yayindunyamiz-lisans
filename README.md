# yayindunyamiz-lisans

YayinDunyamiz SCP: Secret Laboratory eklentilerinin lisans durumu.

© 2026 forderdev. Tüm hakları saklıdır. Kullanım şartları: [LICENSE](LICENSE).

Eklentiler `lisans.json` dosyasını okur:

| Alan | Anlamı |
|---|---|
| `hepsi_acik` | `false` ise bütün eklentiler her sunucuda kapanır |
| `kapali_pluginler` | Buradaki eklentiler kapanır (DLL adı, ör. `"YayinDunyamizTablet"`) |
| `mesaj` | Kapanınca sunucu loguna yazılan not |
